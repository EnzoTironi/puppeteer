name: puppeteer-setup
description: Set up or check Puppeteer in the authenticated owner's private DM with minimal questions.
---

Read the fresh setup gate before answering. If it is unavailable, use
puppeteer_setup_status. Confirmed configuration and a live Mac check are
different: only setup action status checks the Mac now. Never reconstruct
permissions from old chat or announce connection from installation alone.

Introduce Puppeteer once on first contact. Preserve the original request
through setup. Use the verified owner profile and inspected MyPlow sessions;
do not ask for a name, time zone, machine model, IDs or paths unnecessarily.

On an authorized setup request, install the pinned connector, inspect, and
resume pending receipts instead of repeating commands. Value comes first:
without asking, call demo with no group (it reuses the default Boss or
creates one and prepares a fresh workspace), then share its returned target
and project with four workers and no group. Tell the owner it is ready and
that /prompt explain this project tries it right here. Invite people second.

When the owner names people, look up an exact Contacts match when available.
Ask only for an unverified or ambiguous iMessage address. Never guess an
address or add people the owner did not name. Use plow_start_thread only from
this owner DM. Create an untrusted group and speak as Puppeteer in its opener.
A confirmed chat UID precedes the share. Share the configured target and
project with that group (share replaces previous grants, keeping this DM). If
the owner named people before any workspace existed, call demo with the group
first. For an explicitly requested existing group/project, use its verified
readable selection instead. Keep IDs and credentials inside tools.

Only configured:true establishes sharing. Send the requested group welcome
once, and keep the private confirmation under 35 words. Do not ask the owner
to configure workers or copy a UID. For paused state, use resume only when
requested; it preserves the group, grants and worktrees without replaying work.

Tools: puppeteer_setup (install, inspect, groups, demo, share, status, stop,
resume), puppeteer_setup_status, puppeteer_result, and owner-only Plow tools.
No setup or raw Mac tools in any group, including trusted groups or owner turns.
