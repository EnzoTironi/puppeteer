# Live venue checklist

Run against the actual owner's Plow account, Mac, Latch and physical iMessage
group. Automated gateway fixtures simulate phone transport and native workers.

1. Deploy the published image on a free line. Verify startup, seven plugin tools,
   one Agent Index report, and Puppeteer identity despite an old line label.
2. In the owner DM, request setup. Confirm one short introduction, actual Mac
   inspection, default Boss reuse/creation and one question about the first guest.
3. Name a contact. Resolve one exact address when Contacts is available; otherwise
   request that address. Never choose an ambiguous contact automatically.
4. Create or select a group. Confirm one fresh workspace, four workers and
   confirmed sharing before the welcome. Repeat setup without duplicate resources.
5. Check the native OpenClaw cron list: exactly one puppeteer-recover command job,
   every five minutes, no delivery, preserving unrelated owner jobs. Reconcile again.
6. Send ordinary chat, a quoted command, leading spaces, /PROMPT and /promptfoo:
   no reply, cloud model call or Mac task. `/prompt what?` gives help only.
7. Two people submit tasks. Check distinct names/receipts/worktrees and out-of-order
   results. One person's follow-up preserves only their own prior context.
8. Trigger an actual Latch approval. Announce it once, resume the same receipt,
   and never claim completion from submission alone.
9. Restart after a queued receipt. Obtain the original result once. Check that
   gateway watcher and scheduled recovery do not repeat sends or native work.
10. `/prompt ask owner Which file should we change?` reaches only the owner DM.
    No group handoff announcement. The owner's explicit current answer reaches
    that original group once. A private answer cannot change permissions.
11. Pause privately, reject a new task accurately, then resume privately. Keep
    the same group/workspace/grants and preserve cancelled/uncertain work.
12. Re-share only with the owner DM. Verify group coding, stored-result disclosure
    and private-question relay are revoked. Close only this demo's workers.

Record the exact candidate digest, actual device/account/group, screenshots,
receipt IDs, local test output and any failure. Venue verification is incomplete
until these physical transport checks pass on Sam's Mac.
